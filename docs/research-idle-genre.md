## 三、12 款代表作的核心循环解剖

格式：核心循环｜时间结构｜成长结构｜经营维度｜决策点

1. **咸鱼之王**（大厂）— 挂机推图攒资源 → 招募/升星咸将配阵营 → 战力提升 → 推更远关卡。时间：在线 5-15 分钟段为主，离线体感弱。成长：指数，无转生，靠开新区。经营：无空间无资源链。决策：阵营光环/站位 2-3 组。「等数字变大」占比高。
2. **寻道大千** — 挂机砍树掉落 → 装备鉴定套装/灵兽养成 → 境界突破 → 解锁更高效砍树。挂机动画常驻在线，离线弱。指数+境界线，无转生。经营：无。决策：装备流派（低-中）。
3. **菇勇者传说**（4399）— 点神灯抽装备 → 自动战斗推关 → 收益买更多神灯 → 抽装鉴品循环。在线挂机为绝对主体验，离线微薄。指数，无转生，大 R 驱动。决策：抽卡时机（低）。爽点=彩票心理；口碑分化。
4. **Melvor Idle**（独立 90.0%）— 训练技能挂机 → 资源合成/制作转化 → 装备+战利品 → 刷更高效图。**深度离线是核心机制**，在线只做决策（换技能/订单/交易）。线性+技能表解锁，**有明确「全完成」尽头**。经营：库存/订单系统+技能间资源链。决策密度**高**。放置类里最高。
5. **NGU IDLE**（免费 95.6%）— 挂机打怪攒能量 → 维度升级 → 战力新高打更远 → 重生转永久加成。在线为主，目标=看数字涨。**指数级 prestige 套娃**（能量→永久能量→魔能）。经营：无（一页面板）。决策：维度比例、重生时机（低-中）。
6. **Mr.Mine**（免费 91.6%）— 挖矿出货 → 升级矿工/设施 → 解锁深层与科技 → 产量跃升 → 新大陆转生线。在线操作节奏强+离线中等，回来结算感足。指数+资源分层，多轮重置。经营：竖向「深度」空间感+弱资源链。决策：科技顺序、新大陆时机（中）。
7. **Leaf Blower Revolution**（免费 94.1%）— 吹叶收集 → 升级吹风机/装备 → 解锁区域与隐藏机制 → 自动化 → 挂机。手动爆发+挂机并存。巨大数值+迷宫式隐藏系统。决策：隐藏机制发掘（**「发现感」是杀手锏**）。
8. **Farmer Against Potatoes Idle**（免费 94.7%）— 种收土豆 → 打土豆怪防收割 → 掉落装备/技能 → 历法强化 → 更高波次。在线战斗为主，离线 24h 上限偏短，设计成「想常回来」。决策：流 build、历法选择（中）。
9. **(the) Gnorp Apologue**（$6.99 94.8%）— 羊群冲撞岩石 → 反弹伤害 → 能量买科技/解锁弹珠 → 打碎岩石=完成单局 → 跨局研究永久化。**单局制**（几十分钟~几小时）。决策：弹珠混搭/单流派、科技顺序（高）。**看得见的物理反馈极强**。
10. **Stacklands**（96.0%）— 叠卡生产 → 合成发现新卡/科技 → 白天经营晚上打怪 → 村庄成长到周期结束或覆灭 → 重开。即时制+昼夜倒计时，**在线为主、无离线收益**——反「挂机」的时间压力设计。空间=卡牌堆叠区，资源链=合成配方表（强）。决策：卡牌组合、事件取舍（高）。
11. **Spirit City: Lofi Sessions**（97.6%）— 现实专注计时（番茄钟）→ 房间/宠物陪伴动画成长 → 氛围与收集满足 → 更愿意挂机。**纯陪伴型**，无离线收益概念。**无数值**，收集/装扮线。**「情绪价值」替代「数值成长」的 97.6% 好评证明这条路成立**。
12. **动物餐厅**（独立 iOS 4.70/16.2万）— 顾客点餐自动制作 → 收益买装修/菜谱/店员 → 接待力上升 → 图鉴+信件剧情长线。**离线收益是重要组成**（收菜式）。线性慢数值，无转生。空间装扮+店员排班+菜谱解锁。**中国独立开发者做「放置+店铺经营」的标杆**。

## 六、空白组合假设（10 个，均满足单机/无大美术/21 天单人可做）

1. **放置 + 有限时间 + 不可逆结局**：「世界第 N 天冻结」倒计时经营，每个决策消耗天数，结局永久（离线也推进）。主流放置要无限留存，倒计时反商业化 → 大厂不做。
2. **放置 + 生态/天气因子控制**：调「雨/光/地热」旋钮，荒原按生态链长成绿洲（Terra Nil × idle）。需实时模拟+生态美术 → 没人碰。
3. **放置 + 配方发现/实验**：深夜食堂，食材组合→未知菜谱（Little Alchemy 式规则合成），图鉴=菜谱；顾客自动来但点的是你没见过的菜。火锅店/沙威玛全是固定菜单，无人做「发现层」。
4. **放置 + 微观际遇模拟**：几个小人带着意愿自动生活/开店/吵架，你只调环境参数与代价（Lakeburg 71.8% 证明这条被做砸了，缺口仍在）。
5. **放置 + 逆向经营**：拆迁/破产/污染物代理，数字**逆向**膨胀（废除越多收益越大）。已验证的「花钱模拟器」题材只做了花钱。
6. **放置 + 听觉/电台成长**：挂机产出「声纹/听众」，程序化音频当反馈曲线。音频门槛+主流认为放置不值得音频 → 空白。
7. **放置 + 生态缸参数经营**：藻→虾→鱼食物链自循环，只调「光照/营养/温度」。Chillquarium 近但无「系统级生态」层。
8. **放置 + 时间旅行 prestige 带不可逆节点**：每个宇宙有自己的「必死结局」，死亡触发资源回流上宇宙。CivIdle 碰过但执行烂。
9. **放置 + 单局制经营肉鸽**：每局随机「店铺/星球+目标+debuff」，完成解锁下一张局卡（gnorp 无经营、Stacklands 无挂机，两者都没人合过）。
10. **放置 + 整理/收纳收益化**：收纳/整理在 CN 双端都是热度题材，但都是单次爽，无人做「整理→持续产能」的放置化。

## 八、Top 3 推荐

### 🥇 D1「末日小铺 —— 有限时间不可逆放置经营」
- **机制**：世界第 N 天永久冷冻；离线/在线都推进天数；每次进货/装修/研发/救人决策消耗天数且不可逆；结局（含坏结局）永久定格并生成「经营日记」
- **为什么没人做**：倒计时=主动赶客=反放置主流商业逻辑（留存/时长/买量全冲突）
- **放置感保留**：✅ 完全保留——产出与顾客全自动，决策只是「把时间花在哪」
- **21 天可行性**：纯数值+事件文本+单屏 UI，无战斗无寻路无美术资产。难度**低**
- **差异化红利**：评审见过 1000 个「数字变大」，没见过「数字在倒数」；天然无联网无内购不逼氪，与赛事条款和 iOS 审核零冲突

### 🥈 D3「配方实验食堂（发现型烹饪放置）」
- **机制**：深夜小食堂；顾客上门口味随机；你买食材做组合实验，命中隐藏菜谱→图鉴+口碑+解锁新顾客群
- **为什么没人做**：厨艺放置 CN 爆款（火锅店 4.88/31.5万、动物餐厅 4.70/16.2万、伯吉厨房 9.4）全是「点单→上菜」固定菜单；「未知→试错→命名」的发现弧光无人做
- **21 天可行性**：规则化合成表 2-3 天；挂机顾客+口碑循环 2 天；一周可玩，余量做命名系统。难度**低-中**
- **差异化红利**：骑在最热品类上做反主流设计，「我合成出了这道菜」天然适合截图/短视频

### 🥉 D7「挖掘×策展叙事博物馆」
- **机制**：派遣小队自动挖掘（离线也挖），你处理文物：鉴定→布展→写来历，展览热度=收益
- **为什么没人做**：考古致富（2026-09，Demo 93% 好评）刚验证挖掘放置可行，但经营是「卖钱提速」；**策展叙事层仍是零供给**
- **21 天可行性**：挖=数值表；策展=网格+文本库；不做 3D。难度**中**（21 天内控制在 30-50 件文物）

**备选**：D5 逆向经营（黑暗题材被否时）或 D2 生态因子控制（视觉奇观最强，适合竖屏短视频）。
