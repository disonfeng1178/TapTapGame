# TapTap / App Store 中国区上架合规速查

> 研究日期 2026-09-27，来源均为政府机关 / Apple / TapTap 开发者中心一手文件 + 行业交叉验证
> 完整报告见会话记录；本文只保留对本项目有决策影响的部分

## 三条硬事实

| 事实 | 影响 |
|---|---|
| **无版号 ≠ 不能上线**。免费无内购（可含广告）实践上可无版号上 App Store；TapTap 明确支持「预约 / 试玩版 / 测试」 | 项目**可以先不做版号上线** |
| **个人不能申请版号**。必须挂靠有网络出版资质的出版单位 + 以公司为运营单位（营业执照 + ICP 许可证）。官方受理后 80 个工作日，**实际全流程 6–18 个月**，代理费 ¥1.5–5 万 | 版号不是"努力一下就能拿到"的东西 |
| **APP 备案对所有 App 强制**（新 App 2023-09-01 起，存量大限 2024-03-31）。苹果 2024-04 起提审强制校验。**个人主体可备案** | 联网（含广告请求）必须有备案号 |

**另**：实名认证 + 防沉迷是**独立于版号的底线**，测试期也要 100% 接入。TapTap 提供 TapSDK 实名模块（对接中宣部系统），免费，几天工作量。

## iOS 的特殊现实

- **iOS 上"TapTap 上架"实质就是"App Store 上架"** —— 苹果不允许其他分发，玩家从 TapTap 跳 App Store 下载
- iOS 内购 / 买断 → 必须版号 + 强制 IAP + 苹果抽 **30%**（小企业计划 15%）
- TapTap **安卓端 0 抽成**
- 苹果指南 4.7 允许 App 内嵌 HTML5 迷你游戏，但**中国区含内购仍要版号**
- 微信小游戏：无需苹果审核；广告变现可不需版号；软著是提审门槛（行业惯例）

**推论：小体量游戏在 iOS 靠广告回本不现实**（eCPM 低 + IAP 30% + 广告不解决版号）。
所以 iOS 独立游戏实际只有两个结局：
1. 攒够数据 → 启动公司 + 版号（预留 6–18 个月）→ 上内购
2. **完全不商业化**，靠 TapTap 聚光灯的扶持资金和曝光当作品

## TapTap 入驻与审核

- **认证开发者**：个人主体只需身份证正反面 + 手机 + 邮箱，**不需要营业执照**；审核 1–3 个工作日（敏感题材 5–7）
- 企业主体需营业执照（经营范围含信息技术/软件）+ 认证公函（**有效期 1 年需年审**）
- 游戏资料审核 1–3 个工作日（更新版 1 日内）
- **审核红线**：不能有提现/物质奖励、不能夹带联系方式或无关广告、不能引导好评（含邀请好评）、侵权素材需授权书、ICON 不可蹭热词角标、宣传图不可拼接/随意用真人
- **隐私政策必须与 App 内一致、链接真实可访问、不能用论坛帖承载**
- 版号/软著/ICP 上传后**游戏标题不可自行修改**（须走工单）
- 隐私合规还需满足工信部「个人信息收集清单 + 第三方共享清单」双清单

## TapTap 扶持通道

## 明确「查不到官方依据」的部分

- 无版号"试玩版"能否接广告：TapTap 官方只说测试"禁用内购"，**未明文规定广告**；行业认为可行但无官方条款
- 苹果 2026 年对"免费无内购含广告"游戏的实际执行：**官方文本从严（要求所有游戏提供版号），实际执行从宽，无书面豁免**。以实际提交时 App Store Connect 界面提示为准
- 版号代理费 ¥1.5–3 万是 2020 年前后采访数值，2026 行情需自行询价
- 2026-01-10 网信办《互联网应用程序个人信息收集使用规定》网页确认存在，正式稿生效状态未完整核实
