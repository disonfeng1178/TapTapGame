# TapTap 制造对话包 T0-3（v6 配套，直接粘贴）

> 设计依据：`docs/design-final.md` v6 ｜ 数值：`economy.json`（军令 340／金 128／5 阵／4 波）
> 美术基座：`docs/assets-plan.md` §1 ｜ 顺序：记忆 → M0 → M1 → M2 → M3，每轮跑通再下一轮。
> 防坑（实测帖）：每轮点名“用生图模型，不要 emoji/代码占位”；积分小步快跑，大包拆小轮。

---

## 第 0 轮 · 记忆（开工第一句话，先存记忆再开工）

```
请记住本项目的全局约束，后续所有生成都遵守，不用我重复：
1. 竖屏手游，触屏操作，无键盘无 WASD，所有按钮是触屏热区（主按钮≥80px）。
2. 美术/音频资源一律用生图模型与音频生成工具实做，不要用 emoji 或代码绘图占位。
3. 国风战场风格，字体用宋体/楷体类。红=三角、蓝=圆、黄=闪电，形状与颜色双编码（色弱可辨）。
4. 数值以我给的为准，不要自行改动军令/体力/连击/旗规则，改前先问我。
```

## M0 · 只读阵图（约 1 天，验收：变阵 0.5s 动画肉眼可见）

```
做一条只读阵图，放在下屏战鼓区上方，约 60x80px，不可操作：
- 每路一条站位线（前/中/后三档刻度）+ 神机射界扇形；刀盾画方块、神机画三角、斥候画圆点。
- 给我两个阵型的站位：锋矢阵（小兵前压到中线）与环形阵（小兵缩回基地口）。
- 切换阵型时 0.5s 动画过渡到新站位。先跑通这两个阵的切换动画给我看。
```

## M1 · 战鼓连打（验收：10 秒连打不误触，档位闪光）

```
做中央大鼓连打系统：
- 大鼓热区≥80px，每次击鼓 +1 连击（不产军令），连击 5 秒内不断则累积，断了清零。
- 体力条：上限 200，每次击鼓耗 1，每秒回 4。
- 连击档位：x25（闪光+飘字“缴获翻倍”）、x50（飘字“下次发令瞬发”）、x100（弹框提示可背水）。
- 每次击鼓全军齐喝一声（先用合成音占位，后续换生成音频）+ 小兵举武器动作。
- 用生图模型画鼓面，不要 emoji 占位。
```

## M2 · 三色旗键＋搓招（验收：新手 30 秒看懂旗码表）

```
做三色旗键与搓招发令：
- 三键：红三角 / 蓝圆 / 黄闪电，等大，敲击态 واضح。用生图模型画旗面。
- 旗码表（用形状纹排）：锋矢 ▲▲ / 环形 ●● / 鸳鸯 ▲● / 雁行 ▲⚡ / 鱼鳞 ●⚡。
- 规则：按顺序敲对旗码 → 扣旗扣 60 军令 → 读条 2 秒 → 变阵 20 秒。
  4 秒内敲完且无错 = 完美（26 秒 + 多得 1 面主色旗，金边闪光）。
  搓招成功清空连击；搓招输入 4 秒内战鼓锁定（点了无反馈）。
  敲错不扣资源，只断连击；错 2 次以上本次作废。
- 点选兜底：点阵型名直接发，80 军令，20 秒，无完美奖励，不清连击。
- 发令前 0.5 秒预备高亮，可点取消（不扣资源）。
- 手牌旗横排，上限 6 面，溢出转“+10军令”飘字。
```

## M3 · 一阵一怪跑通（验收：可胜可败录屏 30 秒）

```
用 M0-M2 的件拼出最小可玩局：
- 敌人：杂兵 x8（血 6），从右向左走，基地在左。
- 我方：刀盾 x2（血 30，伤 2/s）+ 神机 x1（血 10，伤 4/s，射程 3 格）。
- 开局红/蓝/黄各 1 面旗，军令 0。打鼓攒连击到 x25（+30 军令里程碑），清完杂兵结算 +30，首发锋矢阵。
- 胜利 = 清完怪且基地存活；失败 = 基地归零。跑通后给我录屏。
```
