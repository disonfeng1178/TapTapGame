## 制造对话轮次速查（M1–M12，直接粘给 TapTap 制造）

```
M1 战鼓：中央大鼓连打，+2军令/击，+1连击（5s窗口），体力100（耗1/击回8/s）
M2 旗键：红三角/蓝圆/黄闪电三键，序列输入+4s完美判定+v5读条分级
M3 一阵一怪：锋矢阵+杂兵，变阵20s跑通
M4-M7 垂直切片：第1波8杂兵+胜败判定+背水按钮雏形
M8-M10 四波点名怪：冰甲（鸳鸯）/蜂群+重甲（鱼鳞）/精英（环形或雁行）
M11 兵种+阵型全量：刀盾/神机/斥候+6阵+读条分级+破釜沉舟
M12 遗物+神令：8遗物三选一+空城/草船（瞬发）/火烧
```

减法顺序（时间不够按序砍）：遗物 8→4 → 神令 3→1（留火烧）→ 波次 4→3 → 双色阵 3→1（留鸳鸯）。
**本体不砍**：搓招 6 阵、战鼓连击、背水翻盘。
