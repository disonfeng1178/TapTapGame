## 制造对话轮次速查（M1–M12，直接粘给 TapTap 制造）

```
M0 只读阵图：三路站位线+射界扇形，变阵0.5s动画过渡（不可操作）
M1 战鼓：中央大鼓连打，+1连击/击（不产军令），5s窗口，体力200（耗1/击回4/s），档位x25/x50/x100
M2 旗键：红三角/蓝圆/黄闪电三键，序列输入+4s独占+成功清连击，搓招60/点选80，完美+主色旗
M3 一阵一怪：锋矢阵+杂兵，变阵20s跑通，顶令全损+0.5s预备取消
M4-M7 垂直切片：第1波8杂兵+胜败判定+波次结算30+里程碑x25=首发令+背水按钮雏形
M8-M10 四波威胁点名：重甲高血（鸳鸯/雁行)/高速集群（鱼鳞/雁行)/精英高血（环形/雁行/神令）
M11 兵种+阵型全量：刀盾20/神机30/斥候30+5阵+读条分级（普通2s神令4s)+破釜沉舟+哀兵体力
M12 遗物+神令：8遗物三选一（遗物2定向减费）+空城/草船（瞬发）/火烧
```

减法顺序：遗物 8→4 → 神令 3→2（先砍空城）→ 波次 4→3 → 神令 2→1（留火烧；草船一砍军令目标改回 300）→ 双色阵 3→2（删雁行）→ 2→1（留鸳鸯）。
**本体不砍**：搓招 5 阵、战鼓连击、背水翻盘、军令波次结算、击杀赏金、只读阵图。
