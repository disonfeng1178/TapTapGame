# 《旗令防线》美术 / 音频 / 体验任务拆分（v6 配套）

> 设计：`docs/design-final.md` v6 ｜ 工期排期：`docs/tasks-21day.md`
> 核心结论先行：**UI 主力交给 TapTap 制造内置生图（必须主动点名要，不点名它就用 emoji/代码图占位）；
> 风格基座在外部定好再喂给制造；音乐制造内直出即可。**
> 依据：TapTap 制造实测帖（论坛精华帖“不写一行代码唠出上线游戏”）＋ 站内 UI 美术帖（字体第一）。

---

## 1. UI 交给谁：分工表（可靠度排序）

| 层 | 交给谁 | 为什么可靠 | 怎么做 |
|---|---|---|---|
| ★ 游戏内 UI（鼓／旗键／阵图／结算飘字） | **TapTap 制造内置生图，主动点名** | 实测：点名生图模型后“效果明显好不少”；不点名默认 emoji/代码图占位还会报错 | 每轮对话明确说“用生图模型生成，不要 emoji/代码占位”；竖屏＋移动端＋按钮尺寸一并指定（它默认按 PC 出 WASD/快捷键） |
| ★ 风格基座（三色旗／兵种／主视觉） | **外部生图（即梦/通义万相/可灵）先定，再喂制造** | 外部工具角色/风格一致性更可控；站内有 8 套游戏 UI 提示词可抄 | 定 1 张主视觉＋3 旗面＋3 兵种立绘，同一种子/参考图连发，保证三角红/圆蓝/闪电黄全套统一 |
| ☆ 上架物料（图标／简介图／banner） | **制造一键生成** | 实测：复用美术素材，一致性不错 | 截 3 张实机图＋一键生成图标/banner |
| ☆ 字体 | **站内经验帖＋免费可商用字体** | UI 帖原话：字体是 UI 最重要元素，换字体等于蜕变 | 国风战场选宋体/楷体；先定字体再调其他（T2-5 前定死） |

**防坑三条**（实测帖原话转述）：
1. 开工第一句话就定死“竖屏手游、触屏操作、无键盘”，存进制造记忆，否则它按 PC 出活，后续改 3 倍成本。
2. 生图/音频工具它“不积极”，每轮都要点名；追加角色时盯着它别用 emoji 占位。
3. 预设美术资源少，别指望它现货；积分按“小步快跑”花，大 prompt 拆小轮次（站内有 2000→50 分的省积分帖）。
