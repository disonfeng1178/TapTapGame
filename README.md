# 旗令防线 Signal Line · TapTap 聚光灯 2026 GameJam

单人 21 天做一款**上下分屏「战鼓＋搓招 × 旗语塔防」**小 game，
目标是 **TapTap 聚光灯 2026 21 天游戏创作挑战**。

> 核心玩法：下屏擂鼓攒军令＋搓旗码发令，上屏塔防按阵型守线。
> 你是传令官 —— 平时搓招布阵讲策略，残局擂鼓背水一战拼手速。
> 完整设计见 `docs/design-final.md`（v4 定稿）。

## 怎么跑平衡模拟器

```bash
python3 balance_sim.py                                  # 用 economy.json 跑
python3 balance_sim.py --sessions 30 --minutes 20       # 30 次上线 × 20 分钟 = 10 小时
python3 balance_sim.py --sessions 6 --minutes 3         # 试玩场景（模拟 GameJam 试玩者）
python3 balance_sim.py --ai greedy|max|both             # 单跑某类玩家，默认 both
python3 balance_sim.py --config my.json                 # 换配置
python3 balance_sim.py --dump-schema                    # 看配置字段
```

5 项诊断 + 4 道检查：

| 检查 | 报警条件 |
|---|---|
| 空转 | 最长连续无物可买 > 15 分钟 |
| 决策面 | 购买种类 ≤2，或最高一项 > 70% |
| 曲线节奏 | 最慢档 `Δt/数值倍数` > 中位档 4 倍 |
| 资源垄断 | 单一资源投入 > 70% |
| 重整节奏 | 平均间隔 < 30 分钟 |
| 开局死锁 | `preflight`：没有可买的也没有任何产出 |
| 静态体检 | `lint`：自锁 / 空间陷阱 |
| 决策面对照 | 两种 AI 主买同一件且都 > 60% → 经济没决策 |

模拟器已抓出 6 个真实设计错误（升级倍率空操作、无上限倍率升级=无限最优解、自锁、空间陷阱、开局死锁、重整清零不发启动资金），全部是人肉试玩看不出来的。

## 当前设计方向

**《旗令防线 Signal Line》** —— 上下分屏「战鼓＋搓招 x 旗语塔防」，详见 `docs/design-final.md`（v4）。

- **下屏**：擂鼓连打涨军令＋连击（x30 开背水一战），三色旗键搓招发令（4s 完美判定）
- **旗语总线**：6 阵型旗码（锋矢/环形/车轮/鸳鸯/雁行/鱼鳞）＋ 3 神令底牌（空城/草船/火烧），旗＝资格＋军令＝费用
- **上屏**：3 兵种（刀盾/神机/斥候）按阵型走位开火，180 秒倒计时守 4 波
- **翻盘爽感**：精英贴脸＋残血 → 狂敲战鼓到 x30 → 免旗神令清屏＋狂暴反推
- **差异化**：无游戏把旗语序列输入做成塔防核心指令；手速（鼓）与策略（招）双线互补
- 工具路线：TapTap 制造（H5/创意工坊赛道）做游戏本体，**冲最佳 TapTap 制造奖**；
  本仓库只放文档＋数值脚本（若含 AI 生成内容，在报名材料备注）

旧方向（放置模拟经营 D1「末日小铺」/ D3 食堂）的研究与数值已归档在
`docs/research-idle-genre.md` / `docs/design-placement.md`，主题若不适配可回退。

## 合规红线（做的时候别踩）

- **无版号 ≠ 不能上线**：免费无内购（可含广告）可无版号上架；TapTap 支持「预约/试玩版」
- **个人不能申请版号**：需挂靠出版单位 + 公司主体，全流程 6-18 个月、¥1.5-5 万 → 本作**不商业化**，不涉及
- **APP 备案强制**（个人可备案）：新 App 2023-09-01 起，存量大限 2024-03-31
- **实名认证 + 防沉迷是独立于版号的底线**，测试期也要接 → 用 TapSDK 免费模块
- TapTap 物料红线：无提现/奖励、不夹带联系方式、不引导好评、不蹭热词角标、宣传图不可拼接
- 隐私政策不能用论坛帖承载；提交审核后标题不可自行修改（须走工单）
- 若核心内容含 AI 直接生成部分（剧情/角色/美术），需在报名材料备注
